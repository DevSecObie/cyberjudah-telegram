# Strong's search in the app finds codes and Greek words

- A batch card keeps the identity as the app asked for it (`strong:H0430`). The app matches cards to its own identities, so it had been dropping every card it wrote with zeros. Typing H430 in the app's Search showed nothing.
- A typed code (`H430`, `G0026`) finds that entry and only that entry, instead of every code that contains those digits.
- Accents fold on both sides, and the Greek entries, which the published data leaves without a transliteration, get one written from the lemma the way Strong's does (ἀγάπη agapē, λόγος logos, υἱός huios). "agape" now finds G26, and each Greek entry shows its transliteration.
