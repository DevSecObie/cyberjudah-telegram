- Release manager: a daily "Release status" issue for the iPhone and Android app. It checks the release branch's store build settings (version, build number, bundle id, update channel, App Store Connect app, Firebase file, no staging or local server), checks and build workflows on the release branch, runs waiting for Approve, pull requests into the release branch, and what changed since the last store build. It comments and sends one Telegram message only when something new turns red.
