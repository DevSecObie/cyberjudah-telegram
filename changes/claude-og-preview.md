- New GET /api/og?url=… for the app's saved links: returns the page's title, description, picture and site name as { data: { … } }, the shape the app's links screen reads, so link previews come from our own Worker instead of Bible Strong's preview service. Only a signed-in app reader may ask (rate limited per reader); it only fetches public http(s) pages on the default ports (no IP addresses, internal names or our own hosts, every redirect re-checked), reads at most 512 KB for at most 5 seconds, and caches each page for a day.
