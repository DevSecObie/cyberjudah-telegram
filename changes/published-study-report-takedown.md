# Published studies: report by email, admin takedown, Bible Strong's publishing terms

- Every published study page (/app/published/<id>) has a "Report this study" link. It is a plain mailto to privacy@cyberjudah.io carrying only the study's public link and title, as the Terms describe. The reader's own mail app sends it. The page runs no script, and nothing is recorded about the click. Bible Strong's study page has no report line, so no footer line was added.
- Admins take a study down with `/takedown <id or link>` in a private chat with the bot. Only ADMIN_IDS accounts get an answer, and it is not in the command menu. The study's row is removed, and within a minute (pages are cached for 60 seconds) its page says "This study was taken down." Its id is kept in `published_takedowns` (the id and the time, nothing else), so nothing can be published under that id again. This holds even if the writer had already unpublished it, and the check is part of the publish statement itself, so a takedown mid-request cannot be undone. `GET /api/published-studies/<id>` adds `taken_down: true`, and publishing to that id returns 403 `taken_down`. The writer keeps their own copy in the app. A failed takedown is logged without any report data.
- cyberjudah.io/terms: item 3 ("Your content") is replaced by Bible Strong's three publishing paragraphs, word for word with Le Studio 316 → CyberJudah, from the owner-approved text. "Last updated" is set to November 10, 2026.
- On cyberjudah.io/terms, an indented paragraph under a numbered item now stays inside that item, so the three paragraphs read as item 3 and the list keeps its numbering.
