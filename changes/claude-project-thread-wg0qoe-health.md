- The hourly health check waits out the few minutes when a content publish is loading the search index into the teachings database ("Currently processing a long-running import"), instead of paging the owner about it. An import still running after four minutes still pages.
- Search stays up during every deploy: the search index is now loaded blue-green. A spare copy is built beside the live one with ordinary queries (no database lock), checked (row count and a test search), then switched in one step; the previous copy is kept for an instant rollback. Before, each deploy dropped the live index and locked the database for a minute or two while it reloaded.
