# Bot links to cyberjudah.io only point at pages the site has

- When the bot links to cyberjudah.io instead of the app, a page the website doesn't have (the Timeline, People, a person, a year of classes) now opens the site's home page instead of a "not found" page. The app still opens those screens.
- A link to the glossary opens the glossary (it opened a Bible page that doesn't exist).
