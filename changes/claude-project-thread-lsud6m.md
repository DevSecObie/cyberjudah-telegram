- Security (audit C2): every workflow job that reads the Cloudflare token, bot token or other production secrets now names an environment. Deploys keep `production`; unattended jobs on main (smoke test, search refresh, embedding, note drafts, audio publish, release check) use `automation`; the staging verify job joins `staging`. Once the owner limits `production` and `automation` to main, adds his approval to `staging`, and moves the secrets out of the repository level, a push to any other branch can no longer read them.
