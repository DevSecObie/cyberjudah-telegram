# Auto: a pronoun is not a word to define

- "What does it/this/that mean", "meaning of this", "define it" and the like ask about something earlier in the conversation, not a word. Auto no longer treats them as quick word definitions (it, this, that, these, those, they, he, she, him, her), at any turn. Words that only start like a pronoun ("Hebrew", "theophany", "Ithiel") still are.
- "define" counts as asking what something means, so "define it" is not quick through the short-phrase rule either. "define heresy" stays quick as a word definition.
