# The Final Captivity

A new age in the Timeline that runs from the ships to today. Every event carries:
- title, date, location and people;
- the documented account;
- **the assembly's teaching**, attributed and timestamped to the class;
- scriptures;
- sources, with how precise the date is and what is uncertain;
- where the sources differ.

Nothing is invented. See [[Final Captivity - Editorial Rules]].

## In the app
- An emblem with a "New" badge.
- Each period's details are grouped by theme, with the line "More events are being added".
- The event page has these sections: Summary, Documented history, The assembly's teaching (opens the class at the moment), Scriptures, Where the sources differ, Sources, and Sources reviewed through.
- The content loads only when it is opened, from `app/src/data/final-captivity.json`.
